# 🍝 Recipe Web Page
A simple and responsive recipe web page built using HTML and CSS.  
This project displays a recipe with ingredients and step-by-step cooking instructions in a clean layout.

## 🚀 Features
- Clean and simple user interface
- Displays recipe image, ingredients, and instructions
- Responsive design (works on mobile and desktop)

## 🛠️ Technologies Used
- HTML
- CSS
- 
## 📂 Project Structure
- index.html
- images/

## 🍽️ Recipe Included
- Simple Pasta Recipe

## ▶️ How to Run
1. Download or clone this repository  
2. Open the project folder  
3. Double-click on `index.html`  
   *(or open it in any web browser)*
